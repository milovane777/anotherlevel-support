자주 묻는 질문

데이터는 어디에 저장되나요?
모든 정보는 내 기기 안에만 저장됩니다. 회원가입·서버가 없어 개발자도 볼 수 없습니다.
기기를 바꾸면 데이터가 옮겨지나요?
설정 → 백업 파일 만들기로 파일을 저장한 뒤, 새 기기에서 백업에서 복원하면 그대로 옮겨집니다.
TV에 대시보드가 안 보여요.
휴대폰·아이패드와 TV가 같은 Wi-Fi인지 확인하고, 앱의 TV 화면에 나온 주소(숫자 IP)를 TV 브라우저에 그대로 입력해 주세요. 앱이 켜져 있어야 화면이 바뀝니다.
카카오톡으로 받은 CSV 파일을 어떻게 넣나요?
파일을 누르고 공유 → "모두대시보드로 열기"를 고르면 자동으로 합쳐집니다.
모든 데이터를 지우고 싶어요.
설정 → 데이터 초기화, 또는 앱을 삭제하면 기기 안의 모든 정보가 지워집니다.
